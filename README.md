# AirCast Studio - Ứng Dụng Phản Chiếu Màn Hình iPhone Lên Máy Tính

Ứng dụng Desktop hoàn chỉnh phản chiếu màn hình & âm thanh iPhone/iPad lên máy tính Windows không dây qua chuẩn **Apple AirPlay 2**.

---

## 📦 Bộ Cài Đặt Độc Lập Dùng Cho Mọi Máy Tính (Trong Thư Mục `dist/`)

Ứng dụng đã được đóng gói thành file thực thi độc lập (Standalone Executable), **không yêu cầu cài đặt Node.js hay bất kỳ môi trường lập trình nào**:

| Loại File | Tên File trong thư mục `dist/` | Cách Sử Dụng |
| :--- | :--- | :--- |
| **Bản Portable (Khuyên Dùng)** | `dist/AirCast Studio 1.0.0.exe` | **Chạy ngay không cần cài đặt**. Copy qua USB hoặc gửi qua Zalo/Drive sang bất kỳ máy tính Windows nào để dùng ngay. |
| **Bản Cài Đặt (Installer)** | `dist/AirCast Studio Setup 1.0.0.exe` | Trình cài đặt chuẩn Windows, tự động tạo biểu tượng ngoài màn hình Desktop và Start Menu. |

---

## 🚀 Hướng Dẫn Sử Dụng Nhanh Trên Mọi Máy

1. Mở file **`AirCast Studio 1.0.0.exe`** trong thư mục `dist/`.
2. Nếu máy tính chưa có Apple Bonjour: Ứng dụng sẽ hiển thị nút **"Cài Đặt Bonjour Ngay"**, bạn chỉ cần bấm nút để kích hoạt cài đặt (chỉ cần làm 1 lần duy nhất).
3. Bấm nút **"Bật Máy Chủ"** để chuyển sang trạng thái *Online*.
4. Dùng camera iPhone quét **mã QR** trên màn hình máy tính để kết nối ngay tức thì!
